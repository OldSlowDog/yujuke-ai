# 演示（Demo）

> 聊天页运行在**本地笔记本 GPU + 公网 VPS 反代**之后，需白名单鉴权访问，无法自动抓取实时截图。以下为**代表性会话的结构化转录**与界面还原，用于展示端到端能力。所有内容均为脱敏示例。

## 示例一：读取文件并总结（多步工具调用）

```
用户：帮我把工作区里的 report.md 读出来，总结成三点

助手：
  🔧 调用 read_file（path = report.md）
  ✅ 读取成功（1284 字）
  总结：
    1. 项目背景：在消费级硬件上自托管 128k 上下文私有助手。
    2. 架构：笔记本推理 + 上海 VPS 反代，工具桥 16–17 个能力。
    3. 关键取舍：隐私/成本 vs 显存约束，需量化与守卫。
```

## 示例二：生成网页 + 交付前自检（verify 闭环）

```
用户：做一个会转的风车 CSS 动画网页

助手：
  🔧 write_file（windmill.html）
  🔧 verify__verify（静态验收：@keyframes / 标签闭合 / CSS 引用）
  ⚠️ 自检发现 @keyframes 退化（from,to 同值），自动修复一轮
  ✅ 验收 OK，交付
```

> 该能力由 **verify 验收闭环 + 采纳守卫** 保障：验收失败只追加「修清单」轮，且修复轮若被截断绝不用半页覆盖完整稿。

## 示例三：视觉分析（多模态）

```
用户：（上传图片）这张图里有什么？

助手：
  🔧 vision__analyze（走 mmproj-F16）
  → 描述画面主体、文字与布局
```

## 示例四：无工具负例（不该调时不调）

```
用户：你信命吗？

助手：（直接作答，未调用任何工具）
```
